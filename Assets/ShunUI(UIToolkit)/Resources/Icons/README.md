# Icons

Icon assets used by ShunUI components. Only icons referenced by components are kept here, in both PNG and SVG formats.

To add new icons, use [**exicon**](https://u3d.as/3NhC) — a Unity editor tool to search and download icons from open-source libraries (Lucide, etc.) directly into your project.

Features:
- Downloads in both **PNG** and **SVG** formats at configurable sizes
- Automatically downloads and stores the **license** file for each icon library
- One-click **override to white** — the recommended color for Unity UI sprites (tinted at runtime via USS or component properties)
